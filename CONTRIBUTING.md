Pull Requests are encouraged but must follow these guidelines:
- the branch and commits in question need to provide
  - the originally used ```.dungeondraft_map``` file
  - adhere to the naming scheme set up for this repository and files
  - all files according to [the provided exports](https://github.com/cvoigt/BattlemapsOfTheFrostmaiden#file-formats) for every Level and Prop
- the ```.dungeondraft_map``` file must
  - only reference the **Forgotten Adventures** packs listed in [the prerequisites](https://github.com/cvoigt/BattlemapsOfTheFrostmaiden#prerequisites)
  - not reference mods that are **required** to edit the DungeonDraft map, other than those listed in [the prerequisites](https://github.com/cvoigt/BattlemapsOfTheFrostmaiden#prerequisites)
